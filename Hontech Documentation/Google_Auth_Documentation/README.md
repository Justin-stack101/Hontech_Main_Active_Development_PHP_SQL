## 🛡️ Core Philosophy: The Hybrid Defense-in-Depth Model

1. **Fast Local Access**: Workshop floor staff (technicians and service advisors) use fast, offline-capable credentials to ensure vehicle check-ins never slow down.
2. **Hardened Cloud Governance**: System Owners and Administrators use Google OAuth 2.0 with 2-Step Verification to protect financials, customer databases, and system configuration.
