Developer Testing Protocol: How to Test by Tier Level

Show Guide
Tier 1: Visual / Cosmetic ~5-10 Sec

Changes to text, labels, button styling, colors, padding, or zebra stripes.

⚡ Action: Hard refresh (Ctrl + F5) & spot-check that exact element.
Tier 2: Single-Role Feature ~30-60 Sec

Changes isolated to 1 specific role (e.g. Analytics Period Log Table, Walk-In Input validation).

⚡ Action: Log into that 1 specific account, verify the action, check F12 console.
Tier 3: Shared Core Logic ~2-3 Min

Changes affecting renderStaffTables(), loadData(), Auth, or MySQL PDO APIs.

⚡ Action: Perform a 4-Role Smoke Test (Owner, Admin, SA, Assistant) before committing.
