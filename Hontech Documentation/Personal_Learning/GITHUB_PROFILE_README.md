# MY PERSONAL CAREER ROADMAP

## Career Direction

My main career direction is:

**Full-Stack Web Developer specializing in Cloud Development and Application Security.**

My main profession is software development. I will use cloud computing, cybersecurity, networking, and mathematics to strengthen the applications I build.

## My Main Specialty: Full-Stack Development

I will prioritize:

- Frontend development
- Backend development
- APIs
- SQL and databases
- Authentication and authorization
- Git and version control
- Testing and debugging
- Deployment
- Software architecture
- Maintainable and secure code

Programming and building complete systems will remain the center of my learning.

## My Cloud Specialization

I will learn:

- Microsoft Azure Fundamentals
- Application hosting
- Cloud databases and storage
- Identity and access management
- Secret and configuration management
- Monitoring and backups
- Virtual networks and subnets
- Firewalls and access rules
- DNS and load balancing
- Containers and deployment pipelines when needed

Azure Fundamentals will give me the introduction. My real portfolio evidence will be an application that I successfully deploy to Azure.

## My Security Specialization

I will learn and apply:

- Secure authentication
- Password hashing
- User roles and permissions
- Input validation
- Parameterized database queries
- Protected APIs
- Session and token security
- Safe file uploads
- Secrets management
- Security headers
- Logging and monitoring
- OWASP web vulnerabilities
- Authorized security testing
- Fixing vulnerabilities and testing again

I will perform cybersecurity activities only on systems that I own or have explicit permission to test.

## My Networking Foundation

I will prioritize:

- OSI and TCP/IP models
- IP addressing and subnetting
- TCP and UDP
- Ports
- DNS and DHCP
- HTTP and HTTPS
- TLS and certificates
- Routing
- NAT
- VLANs
- ACLs and firewalls
- Packet analysis
- Cloud networking

Basic wiring and device configuration are enough for my developer direction. I do not need to become an advanced cabling or network-hardware specialist.

I will use networking theory to understand how my frontend, backend, database, cloud services, and users communicate.

## My Mathematics Foundation

I will progress through:

1. Arithmetic
2. Pre-algebra
3. Basic algebra
4. Binary numbers
5. Logic
6. Discrete mathematics
7. Statistics and probability
8. Calculus only if useful later

Calculus is optional for ordinary full-stack development. Mathematics should support my programming—not prevent me from building projects.

## My Study Priority

- 60% — Full-stack programming and building projects
- 15% — Cybersecurity and secure coding
- 15% — Networking and Azure
- 10% — Mathematics

During the capstone, I can give programming and project development even more time.

## My Career Progression

1. College student completing a capstone
2. Junior Full-Stack Developer, Backend Developer, Associate Software Engineer, or Cloud Developer
3. Full-Stack Cloud Developer
4. Secure Application Developer
5. Possible future specialization in Cloud Security, DevSecOps, or Application Security
6. Senior developer or software engineer after gaining professional experience

## My Immediate Action Plan

1. Finish the essential features of my capstone.
2. Stabilize the backend, APIs, and database.
3. Add authentication, authorization, validation, logging, and testing.
4. Review the application using lessons from cybersecurity.
5. Fix the most important security weaknesses.
6. Connect networking lessons to the application's protocols, ports, DNS, HTTPS, and firewall rules.
7. Complete Microsoft Azure Fundamentals.
8. Deploy a safe version of the application to Azure.
9. Document its architecture, security, networking, deployment, and testing.
10. Turn it into a professional portfolio case study.

## My Portfolio Goal

I will build at least one complete application containing:

- Responsive frontend
- Backend API
- Properly designed database
- Secure login
- User roles and permissions
- Protected routes
- Validation and safe queries
- Logging and error handling
- Automated tests
- Azure deployment
- HTTPS
- Monitoring and backups
- Architecture diagram
- Security report
- Clear README and documentation

## My Rules

- Finish projects before collecting more tools.
- Install software only when a project or course needs it.
- Become productive with one technology stack before learning several.
- Combine theory with practical labs.
- Use cybersecurity skills ethically.
- Treat security as part of development.
- Document problems, decisions, fixes, and results.
- Measure progress by completed systems—not by the number of courses or tools collected.

## Final Professional Identity

**I am developing into a full-stack web developer who builds secure, cloud-ready applications and understands the networks beneath them.**

I do not need to know everything before beginning. My progress will be measured by the systems I finish, the problems I can explain, and the improvements I can prove.
