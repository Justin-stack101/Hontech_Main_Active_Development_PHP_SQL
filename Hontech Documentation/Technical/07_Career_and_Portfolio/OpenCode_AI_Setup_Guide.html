2. OpenCode AI: Overview & Execution

OpenCode is a terminal-native AI engine. Since standard Windows environments protect global file systems (restricting npm install -g without Administrator escalation), the command utility should be run using npx on-demand.

Using npx installs the CLI directly inside a temporary cache folder, ensuring zero registry conflicts.

3. Setup Instructions (Running local)

Open your terminal inside VS Code and execute the setup tasks sequentially:

Important Execution Note
Windows PowerShell blocks script runs by default. Running commands via npx bypasses this execution block smoothly.

Step 1: Set up your API key environment variable:

# If using Gemini (Recommended & Free Developer tier)
$env:GEMINI_API_KEY="your-gemini-api-key-here"

# If using OpenAI (GPT-4)
$env:OPENAI_API_KEY="your-openai-api-key-here"

# If using Anthropic (Claude)
$env:ANTHROPIC_API_KEY="your-anthropic-api-key-here"

Step 2: Initialize the interactive assistant:

npx opencode-ai

5. Local Configurations (100% Free & Private)

If you prefer to operate the model locally without signing up for cloud API keys, follow these instructions:

  1. Download and install the system engine at ollama.com.
  2. Open your terminal and pull a coder model (e.g. Qwen or Llama 3): 
    ollama run qwen2.5-coder:7b
  3. Launch OpenCode pointing to your local server port: 
    npx opencode-ai --local
