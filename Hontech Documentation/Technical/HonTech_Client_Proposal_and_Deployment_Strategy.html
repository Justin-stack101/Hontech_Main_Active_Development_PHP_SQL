1. Executive Summary

Running a busy auto center depends on speed and clear communication. Today, HonTech AutoCenter relies on paper claim stubs and verbal updates between the front desk, the service bays, and waiting customers. This creates avoidable bottlenecks: the front desk cannot see what mechanics are doing in real time, mechanics wait on approvals that get lost in the shuffle, and customers in the lounge are left guessing about the status of their vehicle.

This proposal introduces the HonTech Operations System, a fully digital, real-time management dashboard that connects the front desk, service bays, and customer lounge on one shared platform—with no one needing to leave their station to stay informed.

Why This Matters to HonTech

  • Speed & Organization — staff always know exactly which vehicles are on which lifts and what stage each job is in.
  • Customer Trust — a live status monitor in the lounge keeps customers calm, informed, and confident in the shop.
  • Cost Efficiency — the system is built to run on a local network, eliminating recurring monthly cloud hosting fees.
  • Absolute Privacy — customer and vehicle data stay physically inside the HonTech building at all times.

The remainder of this document walks through the recommended architecture, local domain network configuration, hardware requirements, full cost comparison, investment structure, security posture, and the step-by-step rollout plan that will bring this system to life on the shop floor.

2. Architecture Strategy & Local Domain Addressing

We recommend deploying the HonTech Operations System on a local intranet server rather than a cloud-hosting platform. This decision is grounded in three priorities that matter most to a shop like HonTech: eliminating recurring costs, minimizing the technical knowledge required to keep the system running day to day, and guaranteeing that sensitive customer data never leaves the premises.

2.1 Local Wi-Fi Domain Name Resolution (http://hontech.ph)

To ensure maximum convenience for staff and waiting room display monitors, access to the server does not require memorizing numerical IP addresses (such as 192.168.1.105). Instead, we configure a Clean Local Domain Name (e.g., http://hontech.ph or http://hontech.local) directly on the shop's local Wi-Fi router network.

💡 Client & Adviser Technical Advantage: This local domain setup operates for ₱0 monthly fees, requires zero internet registration paperwork, and remains 100% operational offline even if external internet service goes down.

Priority How Local Deployment & Local Domain Delivers It
Lower Cost No monthly hosting or domain fees — a clean local address (http://hontech.ph) replaces years of recurring bills.
Simplicity Managed entirely through a familiar Windows interface — staff type http://hontech.ph into any tablet or TV browser.
Data Privacy All records stay on-site on the shop's own server, never transmitted to a third-party data center.

To run the local server architecture, HonTech will need to prepare the following on-site hardware.

3.1 Primary Application Server (Local XAMPP Server)

This machine is the brain of the operation and should remain powered on during all business hours.

Specification Requirement
Form Factor Desktop PC or Mini-PC (avoid laptops — 24/7 plug-in use risks battery swelling)
Operating System Windows 10 or 11 (64-bit)
Processor Intel Core i3 (10th Gen+) or AMD Ryzen 3
Memory (RAM) 8GB DDR4 minimum, 16GB recommended
Storage 256GB SSD required for fast database read/write speeds
Networking Wired RJ45 Ethernet connection to the shop router (Wi-Fi not recommended for the server)

Budget note: a new machine meeting these specs runs approximately ₱16,500–₱22,000. If HonTech has a spare desktop on hand, it can be wiped and repurposed to reduce this cost to ₱0.

3.2 Staff Terminals (Front Desk & Service Advisors)

  • Standard PCs, budget laptops, or tablets (e.g., iPads)
  • Any device capable of running a modern web browser — Chrome, Edge, or Safari

3.3 Waiting Lounge Broadcast Monitor

  • 40-inch or larger Smart TV
  • Built-in web browser, or a streaming stick (Chromecast / Fire Stick) to display the live dashboard

4. Financial Analysis: Local vs. Cloud

Choosing a local server shifts the cost structure from a recurring monthly expense to a single upfront asset purchase — with substantial savings over time.

Expense Category Cloud Deployment (AWS / DigitalOcean) Local Intranet Server (XAMPP + Local Domain)
Server Hardware ₱0 (rented off-site) ₱16,500 – ₱22,000 (one-time)
Monthly Hosting Fee ₱1,300 – ₱2,700 / month ₱0 / month
Domain Name Fee ₱800 / year (hontech.com) ₱0 / year (Clean Local Address: http://hontech.ph)
Database Storage Limits Pay-per-GB, scaled pricing Unlimited (up to 256GB local SSD)
Internet Bandwidth Costs Subject to provider fees ₱0 (runs on local shop network)
5-Year Total Estimate ₱80,000 – ₱165,000+ ≈ ₱22,000 total

💰 Bottom line: Over a five-year horizon, the local deployment saves HonTech an estimated ₱58,000 to ₱143,000 compared to an equivalent cloud-hosted solution.

5. Investment & Support Structure

5.1 System Development (One-Time Cost)

To keep the transition manageable, the software development fee is divided into two milestones:

  • Project Initiation (30%): an initial deposit to begin hardware preparation and setup work.
  • Final Turnover (70%): the remaining balance, due only once the client is fully satisfied with the Dry Run and the system is actively supporting shop operations.

5.2 Complimentary Support & Future Maintenance

  • 1–2 Months Free Maintenance (tentative): as the system is newly deployed, the first 1–2 months after launch include free maintenance and bug fixes while staff adjust to the new workflow.
  • Ongoing IT Retainer (optional): after the free period, HonTech may opt into a maintenance contract covering routine database backups, password resets, and disaster recovery. Even with a modest retainer, total savings versus cloud hosting still exceed ₱165,000 over five years.

6. Security, Data Privacy & Maintenance

Running on a local XAMPP server rather than the cloud brings meaningful security and operational advantages:

  • Physical Security — the customer database (names, phone numbers, vehicle records) never leaves the HonTech building.
  • Air-Gapped Isolation — the server is not exposed to the public internet, so it cannot be breached remotely by internet scanners.
  • Data Sovereignty — HonTech owns 100% of its data, with no reliance on third-party cloud providers.
  • Local Subnet Domain Security — http://hontech.ph resolves strictly within shop router boundary, keeping internal shop operations invisible to external networks.
  • Zero Command-Line Administration — the system is fully managed through a standard Windows interface—no Linux knowledge required.
  • One-Click Boot — starting the server is as simple as powering it on and opening the XAMPP Control Panel.
  • No Cloud Outages — the system stays fully operational even if the shop's external internet connection goes down.

Phase 1 — Procurement & Setup

  • Procure a server PC, or repurpose a spare unit; assess the lounge TV setup.
  • Physically install and wire the server PC to the local router.

  • Install XAMPP, migrate the HonTech database, and test terminal connections for fast load times. Configure local router domain entry (http://hontech.ph).

Phase 2 — On-Site Client Testing ("Dry Run")

  • Staff continue using paper stubs for safety while also entering data into the new digital system.
  • Goal: let staff stress-test the software and get comfortable with the workflow without risking live operations.

Phase 3 — Staff Training & Go-Live Cutover

  • Conduct final training sessions informed by Dry Run feedback.
  • Officially retire paper stubs — from this point forward, all intake and status tracking is fully digital.

Phase 4 — Post-Launch Observation (Free Maintenance Period)

  • Developer closely monitors the system for 1–2 months to ensure stability, resolve bugs, and support staff adoption.

8. Project Deliverables

Upon final payment and official Go-Live cutover, HonTech will receive the following, ensuring full ownership and understanding of the system:

  • User Manuals — step-by-step PDF guides with screenshots for front desk and service advisor staff.
  • Administrator & Security Guide — instructions for the owner on password resets, analytics, and managing employee access.
  • Emergency Protocol Document — clear steps for server crashes, power outages, or internet loss, including temporary fallback to paper stubs.
  • Source Code License / Contract — the legal document defining code ownership and terms of use.
