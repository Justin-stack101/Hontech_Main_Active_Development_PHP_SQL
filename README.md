## 🚀 Key System Capabilities

1. **Digital Whiteboard Queue Replacement:** Eliminates smudged handwriting, lost repair records, and accidental erasures with permanent audit-trailed digital records.
2. **2-Hour Express PMS SLA Automation:** Live countdown timers with automated visual alerts when vehicles approach service deadlines.
3. **Customer Waiting Lounge Display:** Real-time synchronized TV queue display for customer transparency and waiting anxiety reduction.
4. **Role-Based Access Control (RBAC):** Strict security boundaries for Owner, Admin, Service Advisor, and Front Desk Assistant.
5. **Dual-Deployment Ready:** Runs 100% offline on shop-floor local intranet (XAMPP) or globally on serverless cloud (Vercel + Supabase) for ₱0 infrastructure cost.

---

## 🛠️ Technology Stack

* **Frontend:** Vanilla JavaScript (ES6+), HTML5, CSS3 (No heavy external frameworks)
* **Backend:** PHP 8.x with secure PDO Database Layer
* **Database:** MySQL / PostgreSQL (Supabase Cloud Compatible)
* **Real-time Protocol:** WebSockets & Long-Polling Event Synchronization
* **Architecture:** RESTful JSON APIs & Modular Adapter Pattern
